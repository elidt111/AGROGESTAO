# Mini-ERP Rural

Sistema web de gestão rural desenvolvido com **HTML, CSS e JavaScript**, criado para auxiliar pequenos e médios produtores no controle administrativo de propriedades agrícolas.

O sistema oferece funcionalidades essenciais de gestão com foco em **controle de estoque, vendas, compras, financeiro e operação offline**, sendo ideal para regiões com acesso limitado à internet.

---

## Sobre o Projeto

O Mini-ERP Rural foi desenvolvido como uma solução simples e eficiente para modernizar a administração rural.

Seu principal objetivo é facilitar o gerenciamento operacional e financeiro da propriedade, oferecendo uma interface intuitiva e acessível.

O sistema foi projetado considerando a realidade do campo, onde muitas vezes há limitações de conectividade e necessidade de ferramentas práticas.

---

## Funcionalidades

### Dashboard
- Resumo geral do sistema
- Indicadores operacionais
- Alertas importantes
- Status de sincronização

### Controle de Estoque
- Cadastro de produtos
- Entrada e saída de itens
- Controle de quantidades
- Histórico de movimentações

### Gestão de Vendas
- Registro de vendas
- Histórico comercial
- Atualização automática do estoque

### Gestão de Compras
- Registro de compras
- Controle de fornecedores
- Entrada automática no estoque

### Controle Financeiro
- Receitas
- Despesas
- Fluxo de caixa

### Produção Rural
- Registro de produção
- Controle de safras
- Gestão de lotes

### Relatórios
- Relatórios operacionais
- Dados organizados para análise

### Funcionamento Offline
- Armazenamento local
- Operação sem internet
- Preparado para sincronização futura
